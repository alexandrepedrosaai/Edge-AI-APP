Windows Setup Guide

Complete step-by-step instructions for setting up Edge-AI-APP on Windows

Prerequisites

System Requirements

  • Windows 10 or later (64-bit)
  • PowerShell 5.0 or later
  • At least 2GB RAM
  • At least 5GB free disk space
  • Administrator access (for some installations)

Required Software

  • Git for Windows
  • Go 1.22 or later
  • Node.js 20 LTS or later
  • pnpm 10.28.2 or later

Installation Steps

Step 1: Install Git for Windows

Download and install Git from the official website:

https://git-scm.com/download/win

Or use Chocolatey if you have it installed:

choco install git -y

Verify installation by opening PowerShell and running:

git --version

Step 2: Install Go 1.22 or Later

Download Go from the official website:

https://go.dev/dl/

Or use Chocolatey:

choco install golang -y

After installation, verify it by opening PowerShell and running:

go version

Set up your Go environment (optional but recommended):

go env -w GOPATH="$HOME\go" go env -w GOBIN="$HOME\go\bin"

Step 3: Install Node.js 20 LTS

Download Node.js from the official website:

https://nodejs.org/

Or use Chocolatey:

choco install nodejs -y

Verify installation by opening PowerShell and running:

node -v npm -v

Step 4: Install pnpm 10.28.2

Install pnpm globally using npm:

npm install -g pnpm@10.28.2

Verify installation:

pnpm -v

Step 5: Clone the Edge-AI-APP Repository

Open PowerShell and navigate to where you want to clone the repository:

cd $HOME\Projects

Clone the repository:

git clone https://github.com/alexandrepedrosaai/Edge-AI-APP.git cd Edge-AI-APP

Step 6: Install Dependencies

Install Node.js dependencies using pnpm:

pnpm install

Verify Go module setup:

go mod tidy

Step 7: Create .env.local File

Create a .env.local file in the project root with the following content:

VITE_ANALYTICS_ENDPOINT= VITE_ANALYTICS_WEBSITE_ID= VITE_APP_TITLE=Edge AI App VITE_APP_LOGO=/logo.svg VITE_FRONTEND_FORGE_API_URL=http://localhost:3001 VITE_FRONTEND_FORGE_API_KEY=

Or use PowerShell to create the file:

@" VITE_ANALYTICS_ENDPOINT= VITE_ANALYTICS_WEBSITE_ID= VITE_APP_TITLE=Edge AI App VITE_APP_LOGO=/logo.svg VITE_FRONTEND_FORGE_API_URL=http://localhost:3001 VITE_FRONTEND_FORGE_API_KEY= "@ | Set-Content -Path .env.local -Encoding UTF8

Step 8: Run the Development Server

Start the web application development server:

pnpm dev

The application will be available at http://localhost:5173

Step 9: Run the Go Application (Optional)

In a new PowerShell window, navigate to the project directory and run:

go run .\cmd\app

Or build the executable:

go build -o edge-ai-app.exe .\cmd\app .\edge-ai-app.exe

Step 10: Build for Production

Build the web application:

pnpm build

Build the Go application for Windows:

$env:GOOS="windows"; $env:GOARCH="amd64"; go build -o edge-ai-app-windows-amd64.exe .\cmd\app

Start the production server:

$env:NODE_ENV="production" node .\dist\index.js

You can use the following PowerShell script to automate the entire setup process:

# Edge-AI-APP Quick Setup Script for Windows # Run this in PowerShell as Administrator Write-Host "Installing Edge-AI-APP on Windows..." -ForegroundColor Cyan # Check and install Git if (-not (Get-Command git -ErrorAction SilentlyContinue)) { Write-Host "Installing Git..." -ForegroundColor Yellow choco install git -y } # Check and install Go if (-not (Get-Command go -ErrorAction SilentlyContinue)) { Write-Host "Installing Go..." -ForegroundColor Yellow choco install golang -y } # Check and install Node.js if (-not (Get-Command node -ErrorAction SilentlyContinue)) { Write-Host "Installing Node.js..." -ForegroundColor Yellow choco install nodejs -y } # Install pnpm Write-Host "Installing pnpm..." -ForegroundColor Yellow npm install -g pnpm@10.28.2 # Clone repository Write-Host "Cloning Edge-AI-APP repository..." -ForegroundColor Yellow $repoPath = "$HOME\Projects\Edge-AI-APP" if (-not (Test-Path $repoPath)) { git clone https://github.com/alexandrepedrosaai/Edge-AI-APP.git $repoPath } # Navigate to project Set-Location $repoPath # Install dependencies Write-Host "Installing dependencies..." -ForegroundColor Yellow pnpm install go mod tidy # Create .env.local Write-Host "Creating .env.local file..." -ForegroundColor Yellow @" VITE_ANALYTICS_ENDPOINT= VITE_ANALYTICS_WEBSITE_ID= VITE_APP_TITLE=Edge AI App VITE_APP_LOGO=/logo.svg VITE_FRONTEND_FORGE_API_URL=http://localhost:3001 VITE_FRONTEND_FORGE_API_KEY= "@ | Set-Content -Path .env.local -Encoding UTF8 Write-Host "Setup complete!" -ForegroundColor Green Write-Host "Run 'pnpm dev' to start the development server" -ForegroundColor Cyan

Troubleshooting

PowerShell Execution Policy Error

Problem: cannot be loaded because running scripts is disabled on this system

Solution: Run PowerShell as Administrator and execute:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Go Version Not Found

Problem: go: command not found

Solution: Ensure Go is installed and added to PATH. Restart PowerShell or add Go to PATH manually:

$env:Path += ";C:\Program Files\Go\bin"

pnpm Install Fails

Problem: pnpm: command not found

Solution: Reinstall pnpm and ensure npm is in PATH:

npm install -g pnpm@10.28.2 pnpm -v

Port Already in Use

Problem: EADDRINUSE: address already in use :::5173

Solution: Kill the process using the port or use a different port:

netstat -ano | findstr :5173 taskkill /PID /F

Git Clone Fails

Problem: fatal: unable to access repository

Solution: Check your internet connection and GitHub access. Try using HTTPS or SSH:

git clone https://github.com/alexandrepedrosaai/Edge-AI-APP.git

Node.js Version Mismatch

Problem: Build fails with Node.js version error

Solution: Ensure you have Node.js 20 LTS or later:

node -v npm -v
