Release Information

Version Numbering

Edge-AI-APP follows semantic versioning:

  • Major: Breaking changes
  • Minor: New features (backward compatible)
  • Patch: Bug fixes and improvements

Release Types

  • Stable: Production-ready releases
  • Pre-release: Beta/RC versions for testing
  • Draft: Work-in-progress releases

Verify Downloads

Each release includes SHA256 checksums for verification. To verify a downloaded file on Windows:

Using PowerShell

Get-FileHash .\edge-ai-app.exe -Algorithm SHA256

Compare the output with the SHA256 checksum provided in the release notes.
