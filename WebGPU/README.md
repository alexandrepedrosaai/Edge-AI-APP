# WebGPU - Edge-AI-APP

## ⚡ Electron & Magnetic Field Demo

Interactive simulation showing electrons orbiting under a magnetic field, rendered over the WebGPU pipeline visualization.

**[▶ Open Demo](https://alexandrepedrosaai.github.io/Edge-AI-APP/WebGPU/electron-demo.html)**

![WebGPU](webgpu-bg.jpg)

### Features

- **60 electrons** circulating in orbital paths with glowing trails
- **Magnetic field lines** rotating dynamically with directional arrows
- **Real-time HUD** displaying electron count, B-field intensity, and average velocity
- Background: WebGPU Buffer Initialization & Data Loading pipeline
