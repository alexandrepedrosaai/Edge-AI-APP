Repository Structure

Explore the multi-language codebase and understand the project architecture

Project Overview

Edge-AI-APP is a comprehensive, multi-language project that combines Go, TypeScript, Python, Verilog, VHDL, Rust, and other languages to create a complete edge AI inference and processing platform. The repository is organized into logical modules, each serving a specific purpose in the overall architecture.

Directory Structure

📦 Root Level

Edge-AI-APP/
├── cmd/                    # Command-line applications
├── internal/               # Internal Go packages
├── server/                 # Express.js backend
├── client/                 # React frontend
├── drizzle/                # Database schema & migrations
├── docker/                 # Docker configurations
├── containers/             # Container definitions
├── k8s/                    # Kubernetes manifests
├── src/                    # Source code (multi-language)
├── python/                 # Python modules
├── rust-core/              # Rust core libraries
├── verilog/                # Verilog HDL designs
├── vhdl/                   # VHDL designs
├── tests/                  # Test files
├── scripts/                # Build and utility scripts
├── .github/                # GitHub configuration
├── docs/                   # Documentation (this site)
├── go.mod                  # Go module definition
├── package.json            # Node.js dependencies
└── README.md               # Project README

🔧 cmd/ - Command-line Applications

Contains executable entry points for the Go application:

  • cmd/app/main.go - Main application entry point
  • Command-line interface definitions
  • Application initialization logic

📚 internal/ - Go Packages

Internal Go packages used by the application:

  • internal/inference/ - AI inference engine
  • internal/pipeline/ - Data processing pipeline
  • Utility and helper packages

🖥️ server/ - Express.js Backend

Node.js/Express backend server:

  • server/index.ts - Server entry point
  • API route definitions
  • Middleware configuration

⚛️ client/ - React Frontend

React application with Vite:

  • client/src/ - React components and pages
  • client/public/ - Static assets
  • Vite configuration

🗄️ drizzle/ - Database

Database schema and migrations:

  • drizzle/schema.ts - Table definitions
  • Migration files
  • Database configuration

🐳 docker/ - Containerization

Docker configurations for different components:

  • Multi-platform Docker images
  • Docker Compose configurations
  • Container optimization

☸️ k8s/ - Kubernetes

Kubernetes manifests for orchestration:

  • Deployment configurations
  • Service definitions
  • Ingress rules

🐍 python/ - Python Modules

Python-based utilities and tools:

  • Data processing scripts
  • ML utilities
  • Analysis tools

🦀 rust-core/ - Rust Libraries

High-performance Rust implementations:

  • Performance-critical code
  • System-level operations
  • FFI bindings

⚡ verilog/ - Verilog HDL

FPGA designs in Verilog:

  • Hardware accelerators
  • Digital logic designs
  • Testbenches

🔌 vhdl/ - VHDL Designs

FPGA designs in VHDL:

  • Alternative hardware implementations
  • Complex state machines
  • Simulation models

🧪 tests/ - Test Suite

Comprehensive test coverage:

  • Unit tests
  • Integration tests
  • Hardware simulations
